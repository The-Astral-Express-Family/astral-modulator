#### 检索方式

提供两种检索方式：

- 正则
- 模糊

同一个请求同时支持正则和模糊，对应 cli 可以同时设置两个参数

逻辑上应该是先正则，再在正则后的结果进行模糊搜索。

#### 如何尽可能避免 Agent 不重复创建 tags？

策略：让 agent 多想

- 【不想做】自动检测tag内容是否与已有tag高度相似。如果相似则提示。
- 二次确认流程：
  - `astral tags create <tagname>`
    - 输出包含当前已有的tags
    - 服务端记录当前新tag进入pending状态，生成唯一校验码（code）发给cli/agent
    - agent三思确认tag不重复之后 `astral tags create <tagname> --comfirm <code>`
  - 类似还有 tags  的删改操作
